# Дома — основа развития

Ратуша I/II/III/IV допускает дома I–III / IV–VI / VII–IX / X–XII. Для следующей ратуши нужны три подключённых, не горящих жилых участка максимального уровня текущей ступени. Квартал 2×2 считается четырьмя участками. Ограничения ратуши не уничтожают старые дома после загрузки.

HOUSE_LEVELS и NEED_LABELS в sim.js — общий источник для симуляции, карточек и схемы. Потребности накапливаются, а не заменяют базовые:

| Уровень | Добавляется |
|---|---|
| I | Дорога |
| II | Колодец и один вид еды |
| III | Посуда и одно дерево рядом |
| IV | Два вида еды и водоносы |
| V | Целитель, работа для 25% трудоспособных и умеренный налог |
| VI | Театр и два дерева |
| VII | Школа и площадь 2×2 |
| VIII | Три вида еды и спокойный район |
| IX | Три дерева |
| X | Работа для половины трудоспособных |
| XI | Полный штат школы |
| XII | Полный штат целителя и театра, пять деревьев |

Рост происходит после двух обеспеченных циклов; ухудшение — после четырёх не обеспеченных. Один цикл — 12 игровых секунд. Глина и гончарная доступны с начала, чтобы уровень III не зависел от ещё закрытой ратуши II. Водоносы получают воду из колодца, держат буфер 16; полный офис накапливает 8 воды за цикл. Один участок расходует 0,25 доставленной воды. Обычная вода из колодца и доставка водоносами — разные потребности.

Дом получает доступ к дороге через одну сухую свободную клетку или соседний дом. Это даёт два ряда жилья; третий не подключается. Для квартала проверяется вся площадь. Точки входа используются наймом, рынком и службами; маршруты работников, покупателей, инженеров, пожарных и сборщиков учитывают подход к дальнему дому. Производства и службы требуют непосредственного примыкания к дороге.

В карточке дома VI уровня при ратуше III можно объединить четыре соседних не горящих дома VI уровня в квадрате 2×2. Все четыре клетки заняты одним объектом; жителей, работников, потребление и нагрузку на службы считают по четырём участкам. По любой клетке открывается тот же объект, снос удаляет весь квартал. Объединение, снос, сохранение и восстановление поддерживают площадь. Квартал при ухудшении условий не распадается сам.

Рынок хранит 120 товаров, потребление еды — 0,1 на жителя за цикл. Пища распределяется между доступными видами. Для определения разнообразия нужен заметный запас каждого вида, не одиночная случайная единица. Склады выше I уровня теперь действительно принимают продукцию сверх старого лимита 120.

На progression.html жильё показано первым. Игровая пирамида, вдохновлённая Маслоу, группирует потребности от выживания до самовыражения. Жёлтые пунктирные пункты — предложения (одежда, бани, праздники, мебель, книги, редкие товары), они ещё не влияют на симуляцию. Заметки сохраняются в браузере и включаются в экспорт JSON.

Проверки: housing-check, housing-browser-check, bootstrap-economy-check; регрессии снабжения, перевозок, найма, служб и морской торговли. Физические товары и службы проверяются отдельно от визуального размера объектов.
