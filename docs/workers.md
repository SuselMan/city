# Работники

Каждый дом предоставляет половину заселённого населения как рабочую силу. Поиск работы проходит по всей соединённой дорожной сети, без прежнего ограничения в 18 клеток. Один человек занимает одно место.

Сначала каждое доступное здание получает одного работника, затем распределяются вторые места и следующие. Приоритет при равных условиях: ратуша, рынок, склад, добыча еды, глина, гончарная, башня. Выбирается ближайший дом со свободным работником; прежние назначения сохраняются при одинаковом расстоянии. Новое предприятие получает шанс начать работу даже при нехватке населения.

Ратуша требует 1 работника, рынок и склад по 2, плантация и рыбалка по 3, охотники и глинокопы и лесорубы по 2, порт 3, гончарная 4, башня 2/4/6/8 на уровнях I/II/III/IV. Колодец обходится без работников. Неполный состав уменьшает производительность. Карточки показывают занятость и причину отсутствия работников; ратуша показывает безработных и вакансии.

Жители идут из назначенного дома к своему месту работы, работают там и возвращаются домой. Проверки: qa/recruitment-check.cjs, qa/building-workers.cjs, qa/tower-workers.cjs.
