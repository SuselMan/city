# Тиходол

Ранний браузерный прототип уютного градостроительного симулятора с tower defence. Phaser 3.90.0, обычный JavaScript, без сборщика и внешних CDN. Игровые изображения сгенерированы встроенным image_gen.

## Запуск

Статический HTTP-сервер из корня проекта. Все рабочие ресурсы уже в assets/. Для обновления Phaser: npm install, затем копирование node_modules/phaser/dist/phaser.min.js в assets/. Симуляция отделена в sim.js, графика и управление в game.js.

## Работает

- Сетка 32×24, дороги и связность с ратушей; обзор, масштаб и миникарта.
- Дома трёх уровней; дорожная доступность воды и рынка, ограниченная вместимость служб, запас еды, посуда, красота.
- Фермы, рыбалка на берегу, гончарная; распределение работников и пешеходные маршруты по дорогам.
- Работники для всех рабочих зданий, кроме колодца. Рынок обслуживает меньше домов при неполном составе; ратуша без работника не торгует и не собирает доход. Башни двух уровней, снаряды, вручную запускаемые волны, два типа врагов, разрушение зданий, ремонт, награды.
- Покупка еды и продажа посуды в ратуше.
- Пауза, скорости 1/2/3×, сохранение localStorage, адаптивное управление.

## Ограничения

Это проверка основного игрового цикла, не вся обсуждённая модель. Нет индивидуального бюджета времени жителей, полноценного рынка труда, развитой торговли, санитарии, образования, развлечений, водоносов и больших строек. Рабочая сила рассчитывается агрегированно, ходящие жители визуализируют маршруты. Враги идут напрямую к ближайшей постройке, без полноценного поиска пути вокруг препятствий. Сезоны пока декоративные. В версии v3 сохранена простая растровая стилистика, но добавлен лёгкий ракурс сверху с видимой боковой стеной. Сохранение локальное; незавершённое нападение при загрузке отменяется без новой награды.

## Проверка

npm run check
node qa/sim-check.cjs
node qa/browser-check.cjs

Последняя команда использует существующий Playwright VPS и приватный URL вне Git. Проверены desktop 1440×1000 и mobile 390×844 в Chromium: загрузка ресурсов, отсутствие JS ошибок и горизонтального переполнения, строительство через UI, карточка, сохранение/перезагрузка, появление врагов. Это не аппаратная проверка телефона или Safari.

Запросы графики и план анимации: docs/art-v3.md, docs/art-v2.md и docs/art-direction.md. Компактные результаты и необходимые скриншоты: qa/. URL размещения в Git не хранится.
